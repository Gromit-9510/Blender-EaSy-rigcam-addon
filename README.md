# EaSy Rig Cam

A simple addon I created while working in Blender. Crane camera rig controller for easier camera management and animation workflows.

## Features

- **Multiple Camera Rig Support** - Create and manage multiple crane camera rigs in one scene
- **Smart Snap Tools** - Snap crane position to 3D cursor, selected objects, or use eyedropper for precise placement
- **Advanced Focus Controls** - DOF settings with distance eyedropper and focus-to-selected functionality
- **Frame Jumping Controls** - Quick timeline navigation with customizable step sizes
- **Preset System** - Save and load camera setups for consistent shots
- **Lock System** - Prevent accidental changes during animation work
- **Dual Interface** - Available in both 3D Viewport sidebar and Properties panel

## Installation

**Requirements:** Blender 4.2 or higher

1. Download `EaSyCaM_v1.py` from the [Releases](https://github.com/Gromit-9510/blender-rigcam-addon/releases) page
2. Open Blender
3. Go to **Edit → Preferences → Add-ons**
4. Click **Install...** and select the downloaded `.py` file
5. Enable **"EaSy Rig Cam"** in the addon list

## Usage

1. **Access the Panel:** 3D Viewport → N-Panel → Rig Cam
2. **Create a Rig:** Click "Create New Rig" to set up your first camera rig
3. **Position Setup:** Use snap tools or manual controls to position the crane
4. **Camera Settings:** Adjust distance, rotation, focal length, and DOF
5. **Animation:** Set keyframes for different camera positions and movements
6. **Presets:** Save your favorite setups for reuse
